# 主线数据约定

当前master: RGB数组(3,6,12,9)，dtype可为uint8或float，数值范围0..255；每块9点取均值后除255，模型输入(B,3,6,12)。
光谱标签(190,)为原始吸光度，不按split重新标准化；波长380..758nm，间隔2nm。
历史dual24配置则读取(4,6,100,3)，5%-95%截尾裁剪均值与灰平衡；其光谱为76点。
feature_scale为显式配置，ratio/log_ratio使用1，不能假定255。
每份输入与spectral_<ID>.npy精确配对；输入错误、非有限值、标签长度错误立即拒绝。
原始照片随机采样十次仍属于同一物理采集组，不能跨split。
后期token分支保留九点维度，multilight分支使用(3,8,72,9)的已成组npy文件。原始分组npz读取代码保留在historical/，本次统一runner不自动猜测npz键或组装光源。
