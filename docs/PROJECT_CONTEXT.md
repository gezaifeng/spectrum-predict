# 接手上下文

## 项目方向

用多色块对透过溶液后的光学响应编码，提取色块RGB，学习到科学光谱仪测得的溶液吸光度谱的映射。
研究路线包括采集、特征处理、训练、性能评估；不同色块及光源提供不同测量响应。

## 开发主线

最初24色块CNN可行性尝试；CNN、残差与U-Net比较后倾向残差；探索峰值与动态波长权重；
引入DCT基底＋逐波长残差双头与DC/TV约束；探索自注意力以建模色块全局联系；
增加到72色块、每块9点和190点谱；再探索八光源输入及数据采集自动化。
当前master依用户要求收束到残差双头，并将72色块规格工程整合进去，不代表历史上已确认的最优模型。
